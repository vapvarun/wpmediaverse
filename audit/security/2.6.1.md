### Flagged by scanners but safe

- `permission_callback => __return_true` on `/mvs/v1/offload-probe/{token}`: the path comes only from a transient the server set (32-hex token, 60 seconds, deleted after the loopback), must resolve inside uploads, and PHP sends no body.
- `X-Sendfile` / `X-Accel-Redirect` headers: the path is realpath-contained and each segment is `rawurlencode`d.
- `sslverify => false`: loopback probes to the site's own address, comparing random bytes.
- `HTTP_IF_NONE_MATCH` / `HTTP_IF_MODIFIED_SINCE` read unsanitised: compared only, never output, after the signature and `can_view` checks.
- No rate limit on `/serve`: the signature is the gate.
- Interpolated SQL in `replace_file_paths`, `ranked_feed_page`, `find_by_hash`, `query_listable_spaces`, `media_ids_before`: values are bound, the alias is one of two literals, `esc_like` is used.
- `direct_url()`: `can_view` runs first; DM media, SVG, readable names and cloud drivers never get a direct address. Documents live in a sibling folder the rule does not reach.
- `PresetActivation`: `manage_options` plus nonce, safe redirect, reason through `sanitize_key` then `esc_html`. The key in the code is the shared free-plugin key.
- Pro stories and challenge messages render as text (`data-wp-text`). Pro permanent delete checks nonce, ownership and trash status.
