## Cross-cutting rule for 2.0.0
No fix leaves a duplicate path or dead code. Shared-root fixes introduce ONE helper and delete the copies: vote-record (A2), delete-cascade (A3), user_login→nicename (B2/B3), chat-panel-visibility gate (B6), online/DM ceiling (B4/B5). Re-grep after each fix to confirm the duplicate/dead code is gone.

## Branch / release
- One branch per release: `2.0.0` in both `wpmediaverse` and `wpmediaverse-pro` (from `main`).
- All fixes land on `2.0.0`. QA verifies each card; fixed cards move to Ready for Testing (`9637173253`).
