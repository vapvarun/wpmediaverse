# 2.1.0 safety. The gate that was supposed to stop a critical feature shipping
# uncovered had never been told that SAFETY is a critical feature — none of the
# tags above is about blocking, reporting, or moderation. Both 2.1.0 incidents
# went straight through it:
#
#   - reporting was dead on every install (403 everywhere, on Free and Pro),
#     while `wp mvs cert` passed 66/66;
#   - the block gate was applied to 3 of ~112 write endpoints, so a blocked
#     member could still favourite, share, battle, and story-view their blocker.
#
# These are cross-actor authorization bugs: correctness depends on a relationship
# between two identities. Nothing that dispatches one GET as one user can see
# them. The journeys behind these tags use two real identities and assert the 403.

# 2.4.0 document library. Documents and media share one table, so containment is
# a query-discipline promise rather than a structural one: every listing carries a
# positive type predicate instead of the table shape making a leak impossible.
# A promise of that shape needs a net under it, and this is the net — without it
# Phase 1 has no proof, which is why the plan calls it a release blocker.
#
# The journey is deliberately adversarial: the seeded document is public,
# published and approved (the most exposed configuration), it is forced into an
# album through the join table, and the fixture's smart collection matches on
# `privacy = public` — so it matches every listing's criteria except type.
