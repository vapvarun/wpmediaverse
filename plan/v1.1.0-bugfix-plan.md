### Fixed (2026-04-06 — this session)
- [x] H1: Delete button on /my-media/ — template bindings used `state.confirm.visible` but store uses flat `state.confirmVisible`. Fixed in dashboard-content.php, album.php, media-single.php
- [x] H2: Album edit doesn't save images — `saveAlbum()` isEdit branch never called `POST albums/{id}/items`. Added items sync call in dashboard-view/view.js
- [x] H3: Video not playing in lightbox — lightbox hardcoded `<img>`, never rendered `<video>`. Added conditional video/audio elements + getters in shared-ui
- [x] H4: Audio upload not possible — no Audio tab in upload modal. Added audio tab, `isAudioMode` getter, extended `uploadAccept`
- [x] H5: BP Activity media upload broken — `bp-activity-media.js` never loaded due to wrong path (`plugin_dir_path(dirname(__DIR__))` vs `MVS_PLUGIN_DIR`)
- [x] M1: Notification links broken — API returned no URL, JS dropped it, template had no `<a>`. Fixed all three: NotificationService, dashboard-view/view.js, dashboard-content.php
- [x] M2: Default privacy not applied — `openUploadModal()` hardcoded `'public'`. Now reads `ctx.defaultPrivacy` from PHP context
- [x] M3: Share button broken — `lightboxShare()` failed silently on HTTP/no clipboard. Made async with error handling
- [x] M5: Album images blurry — `get_cover_url()` default size was `'medium'`, changed to `'large'`
- [x] M6: Grid columns setting ignored — `block.json` had `default: 3` on columns attribute making setting dead code. Removed default
