## Environment note (running the PHPUnit suite locally)
Local MySQL is socket-only; the WP test lib install forces TCP and fails. Use:
`export MYSQL_UNIX_PORT=~/Library/Application\ Support/Local/run/eem4PYdTG/mysql/mysqld.sock`,
`export WP_TESTS_DIR=$TMPDIR/wordpress-tests-lib` (the install put it under
`/var/folders/...`, not `/tmp`), bundled mysql bin on PATH, test DB `wp_mvs_tests`.
See memory `reference_mediaverse_phpunit_setup`.
