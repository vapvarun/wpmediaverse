## Issues fixed in this walk-through

| File | Issue | Fix |
|---|---|---|
| `wpmediaverse/src/blocks/story-viewer/render.php` | Silent `return;` when no active stories — violated Coding Rule #11 ("no silent render fallthrough") for logged-in users who'd see a heading and no body. | Inline empty-state block with `mvs-empty-state` markup + Lucide clock icon + hint copy. Anonymous viewers still see nothing (stories are a logged-in feature; an empty state for anonymous would be noise). |
| `wpmediaverse-pro/includes/Frontend/LeaderboardRenderer.php` | `<ol>` auto-numbers list items + the renderer also outputs its own rank `<span>` → double "1. 1" / "2. 2" markers. | Switched `<ol>` to `<ul style="list-style:none;padding:0;margin:0;">`. The rank span is now the sole marker — flexible for future styling (medals for top 3, etc.). |

Both fixes pass each plugin's local-CI gate (PHP lint + WPCS + PHPStan + coding rules + settings contract + manifest).
