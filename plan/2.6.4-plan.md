- Release notes in the action-prefix format, no em-dashes; free body links to the Pro tag.

## 6b. Release rules that apply (MediaVerse CLAUDE.md)
- A 2.6.x patch is bug fixes only: no default-behaviour change without a filter escape hatch, no schema change (a Migrator bump needs a minor), no removed template or public symbol. The albums/collections capability fix must keep existing role grants working; if it needs a new capability or a changed default it moves to 2.7.0.
- Each fix: sweep the class across Free and Pro and say what was covered in the commit; update `qa/inventory/FUNCTIONALITY-CATALOG.md` for any changed feature; bump `@version` on any overridable template that changes; add a journey and run it against the pre-fix code to prove it fails.
- Run `composer ci` (not only the pre-commit hook) before push.

## 7. Not in this release
- Translations (10454697648), OpenAPI catalogue, caching/scale cards, site/doc copy cards, lightbox reply threading (2.7.0 candidate): all Scope-column work, not reproduced defects.
