## 2.6.1 headline: direct media delivery (shipped earlier, card 10369150277)

Media files are served straight from `uploads/wpmediaverse/` under random names
(capability URLs); /serve stays for DM, documents, SVG, downloads. Off until a
probe proves the server serves the folder (`mvs_direct_delivery`, filter
`mvs_direct_media_delivery`). Privacy tightening renames files
(`MediaFileRotator`), which now fires `mvs_media_files_rotated` for add-ons.

Re-measured 4 Oct (BuddyX, seeded media, cold browser): media directory with
48 files went from 40-48 PHP requests per view (~480 ms first byte each,
32-46 s request time, ~7.7 s of PHP worker time) to 0 PHP requests (~5 ms
each). Activity as guest: 7-8 PHP requests -> 0. Numbers posted on 10369150277
and 10369185494.
