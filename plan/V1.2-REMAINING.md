### 1. Menu Consolidation (UX — Confusing Duplicate Pages)

#### A) Merge Reports into Moderation
**Problem:** Two separate menu items for content review:
- "Moderation" (`mvs-moderation`) — AI-flagged content, pending review
- "Reports" (`mvs-reports`) — User-submitted reports on published content

**Solution:** ONE "Moderation" page with tabs:
- Tab 1: AI Flagged (current moderation queue)
- Tab 2: Pending Review
- Tab 3: User Reports (current reports page content)
- Tab 4: Resolved/Dismissed

**Files to modify:**
- `wpmediaverse/includes/Admin/ModerationQueue.php` — add tab navigation, embed reports
- `wpmediaverse/includes/Admin/ReportsPage.php` (find exact path) — extract rendering into callable method
- `wpmediaverse/includes/Core/Plugin.php` — hide Reports menu item, keep page accessible via direct URL
- `wpmediaverse/assets/css/admin.css` — tab styles for moderation page

#### B) Merge Analytics into Stats
**Problem:** Two separate menu items for performance data:
- "Stats" (`mvs-stats`) — views, downloads, reactions, storage, AI usage
- "Analytics" (`mvs-analytics`) — video play events, engagement scores, completion rates

**Solution:** ONE "Stats" page with tabs:
- Tab 1: Overview (current stats page content)
- Tab 2: Video Analytics (current analytics page content, Pro only)

**Files to modify:**
- `wpmediaverse/includes/Admin/StatsPage.php` — add tab navigation
- `wpmediaverse-pro/includes/Admin/AnalyticsDashboard.php` (find exact path) — extract rendering
- `wpmediaverse-pro/includes/Core/Plugin.php` or `wpmediaverse-pro.php` — hide Analytics menu item
- Both plugins' admin CSS if needed

#### C) Clean up menu order
**Target menu structure:**
```
WPMediaVerse
```

### 3. Log Viewer — Wire Up or Remove

**Problem:** Log Viewer page (`mvs-logs`) shows nothing because `LoggerService` methods exist but are NEVER called anywhere in the codebase. No uploads, reactions, comments, moderation actions, or errors write to the log.

**Options:**
- **A) Wire it up** — Add `LoggerService::info()` calls to key operations:
  - Media upload success/failure
  - AI moderation flag
  - Report submitted
  - Moderation action (approve/reject)
  - Storage operations (S3 upload, CDN purge)
  - User block/unblock
  - Webhook delivery success/failure
- **B) Remove from menu** — Hide Logs until it's properly wired (v1.3)

**Recommendation:** Option A for v1.2.0 — a log viewer that doesn't log is a bad look for a premium plugin.

### 4. Fix Duplicate Quota Package Bug

**Problem:** `wpmediaverse-pro/includes/Core/Migrator.php` line 120 does `$wpdb->insert()` for the default "Unlimited" package with NO duplicate check. Every plugin activation adds another copy.

**Fix in Migrator.php:** Add check before insert:
```php
$existing = $wpdb->get_var( "SELECT COUNT(*) FROM {$wpdb->prefix}mvs_quota_packages WHERE name = 'Unlimited'" );
if ( ! $existing ) {
    $wpdb->insert( ... );
}
```

**Also:** Delete the duplicate from the DB (manually or via a one-time cleanup in the migrator).
